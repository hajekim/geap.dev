Google Gemini Enterprise
핸즈온 워크숍 오프닝 키노트

Google Workspace 및 Google Cloud 인프라를 기반으로 엔터프라이즈 환경에 최적화된 생성형 AI의 핵심 기능과 거버넌스를 이해하고, 실무에 즉시 적용하는 4대 트랙 핸즈온을 진행합니다.

Space 또는 ↓ 키를 눌러 다음 슬라이드로 이동

1. 엔터프라이즈 생성형 AI 아키텍처

Gemini Enterprise는 기업 데이터 주권과 보안 요건을 완벽히 준수하며, 사내 업무 도구와 안전하게 통합됩니다.

📌 사내 데이터 보호 및 격리

사용자 질의 및 입력 데이터는 모델 재학습에 절대 사용되지 않으며, 고객 데이터 보호 경계(VPC Service Controls) 내에서 안전하게 격리 처리됩니다.

⚡ 기존 업무 도구와의 유기적 연동

Google Workspace(Drive, Gmail 등) 및 Microsoft 365 데이터와 실시간 연계하여 권한(ACL) 기반의 안전한 문서 검색 및 업무 자동화를 수행합니다.

2. 역할별 4대 실습 트랙 매트릭스

참석자의 직무 역할(일반 임직원, 기획자, 개발자, IT/보안 관리자)에 맞춰 설계된 체계적인 실습 여정을 안내합니다.

🟢 Track 1

Day 1 Value
전사 임직원 대상
설치 없이 브라우저에서 즉시 체감하는 기본 AI 어시스턴트, 미디어 생성, 데이터 시각화 실습

🔵 Track 2

Agentic Value
기획자 및 파워유저
팀 도서관 소스 기반 콘텐츠 자동 생성, Deep Research 심층 탐색, 노코드 에이전트 구축

🟣 Track 3

Pro Code
개발자 및 엔지니어
Drive/GCS 사내 RAG 연동, Google ADK 프레임워크 기반 Python 커스텀 에이전트 개발 및 Cloud Run 배포

🔴 Track 4

Admin & Security
IT 관리자 및 CISO
GCP 프로젝트 격리, Model Armor 인라인 보안 방화벽, BigQuery SIEM 감사 로그 관제 및 ROI 분석

3. Track 1: Day 1 Value 주요 내용

별도의 설정 없이 웹 브라우저에서 즉시 활용하여 문서 작성과 데이터 분석 시간을 획기적으로 절감합니다.

✨ 개인화 컨텍스트 (pContext)

사용자의 직무, 산업군, 협업 조직 및 이전 대화 메모리를 참조하여 개인에게 최적화된 맥락 기반 맞춤형 답변을 생성합니다.

📊 멀티모달 파일 분석 & Canvas

엑셀(.xlsx) 매출 추이 차트 생성, 파워포인트(.pptx) 요약 표 작성, 그리고 대화 내용으로 구글 슬라이드를 자동 디자인하여 내보냅니다.

4. Track 2: Agentic Value 주요 내용

사내 지식 도서관 연동과 맞춤형 에이전트 설정을 통해 단계별 비즈니스 워크플로우를 구성합니다.

📚 Gemini Notebook 도서관 (5종 생성)

지정된 문서(Gemini, Workspace, Cloud 소스 3종) 기반으로 인포그래픽, 팟캐스트 오디오, 시네마틱 슬라이드, 리포트 3종, 튜토리얼 비디오를 자동 완성합니다.

🛠️ Deep Research & Agent Designer

최대 160회 다단계 자율 리서치 보고서를 생성하고, 노코드 Flow Builder로 시장 분석 및 업무 자동화 에이전트를 조립합니다.

5. Track 3 & Track 4 심화 내용

개발자를 위한 커스텀 마이크로서비스 확장과 IT 관리자를 위한 전사 거버넌스 체계를 다룹니다.

🟣 Track 3: ADK & Cloud Run

Python 기반 Google ADK로 비즈니스 로직을 구현하고, to_a2a() 표준 변환을 거쳐 Cloud Run에 원클릭 배포 후 Gemini Enterprise 에이전트로 등록합니다.

🔴 Track 4: Model Armor & SIEM 관제

개인식별정보(PII) 유출 차단 및 프롬프트 인젝션을 방어하는 Model Armor 7대 테스트를 검증하고, BigQuery로 실시간 RAG 감사 로그를 분석합니다.

6. 업무 목적별 프롬프트 프레임워크 3종

상황과 목적에 따라 가장 적합한 구조화 프레임워크를 선택하여 일관되고 정확한 출력 결과를 도출합니다.

⚡ APE (단순 질의)

Action · Purpose · Expectation
빠른 정보 요약과 사실 검색에 최적화된 직관적인 3단계 기본 구조

🏆 C.R.A.F.T (표준 보고서)

Context · Role · Action · Format · Tone
기획서, 제안서, 공식 메일 등 형식과 톤 제어가 필요한 비즈니스 표준

🎨 CO-STAR (마케팅)

Context · Objective · Style · Tone · Audience · Response
고객 타겟팅 및 브랜드 어조 제어가 중요한 카피라이팅에 최적화

7. 엔터프라이즈 생성형 AI 성숙도 로드맵

단순한 질의응답 보조에서 시작하여 전사 자율 워크플로우와 거버넌스로 발전하는 4단계 도입 여정입니다.

1️⃣

개인 어시스턴트

초안 작성, 번역, 표 분석, 미디어 생성 등 일상 업무 30% 시간 절감

2️⃣

팀 지식 도서관

Gemini Notebook 소스 그라운딩 기반 다형태 콘텐츠 자동 생성

3️⃣

자율 워크플로우

Agent Designer 및 ADK를 활용한 부서별 특화 다단계 에이전트 조율

4️⃣

전사 거버넌스

Model Armor 보안 방화벽, BigQuery 감사 관제, 체계적 ROI 입증
