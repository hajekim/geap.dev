🟣 TRACK 3 · KNOWLEDGE & CONNECTORS

사내 데이터 연동 및 엔터프라이즈 RAG 탐색

Google Drive 커넥터와 사설 GCS 저장소를 연결하여 규정 문서를 RAG 검색하고 최적화 수칙을 익힙니다.

3.1
Google Drive Connector 연동
엔드유저 브라우저에서 Drive 커넥터를 1회 클릭으로 활성화하고 OAuth 권한을 승인합니다.
3.2
사내 규정 문서 RAG 질의
복리후생 내규 및 마케팅 캠페인 문서를 참조하여 출처가 명시된 신뢰도 높은 답변을 도출합니다.
3.3
지식 베이스 최적화 & 거버넌스
시맨틱 청킹 스코어를 높이는 헤딩 구조화, 표/차트 텍스트 병기, 구버전 아카이빙 수칙을 학습합니다.
3.0 ARCHITECTURE & SECURITY

Zero Data Leak: 사내 접근 권한(ACL) 상속 RAG 원리

사용자가 접근 권한을 가진 구글 드라이브 폴더와 GCS 버킷만 검색 대상에 포함됩니다.

🛡️ 엔터프라이즈 데이터 보호 3대 원칙
  • 1. 권한 기반 검색 (ACL 상속): 직급이나 부서별 열람 권한이 없는 문서는 검색 결과에 절대 노출되지 않습니다.
  • 2. 모델 재학습 0% 보장: 사내에서 질문하거나 참조된 모든 문서는 기본 모델 재학습에 일절 사용되지 않습니다.
  • 3. 정확한 출처 문서 링크: 답변마다 원본 파일명과 위치가 명시되어 사실 확인(Fact Checking)이 가능합니다.
⚡ 커넥터 동작 파이프라인
1단계: 사용자 질의 입력 (예: 복리후생 내규 질문)
↓ 커넥터 라우팅 (Google Search OFF, Drive ON)
2단계: 사내 Drive/GCS 저장소 시맨틱 벡터 검색
↓ 상위 청크 추출 & 컨텍스트 주입
3단계: Gemini LLM이 출처가 명기된 정확한 답변 작성
3.1 CONNECTOR ACTIVATION

Google Drive Connector 연동 및 OAuth 인증 4단계

대화창 우측 하단의 커넥터 메뉴에서 실습용 구글 계정으로 Drive 권한을 활성화합니다.

1단계: Enable actions 클릭
2단계: 실습 구글 계정 선택
3단계: OAuth 권한 Allow 승인
4단계: Disable actions 연동 완료
3.2 DRIVE RAG EXPLORATION

Google Drive 사내 복리후생 내규 RAG 질의

구글 드라이브에 업로드된 사내 규정 문서를 실시간 RAG로 탐색하고 출처를 확인합니다.

Drive RAG 실습 프롬프트
내 드라이브에 있는 "복리후생" 문서를 기반으로 자녀 학자금 지원 한도가 재직 기간에 따라 어떻게 다른지 알려줘
💡 실습 팁: 하단 커넥터 설정에서 Google Search: OFF, Drive: ON 상태를 확인하세요.
문서 기반 정확한 지원 기준 도출
클릭 시 원본 파일 위치 하이라이트
3.2 GCS ENTERPRISE RAG

GCS 사설 저장소 비정형 문서 RAG 탐색

Cloud Storage 버킷의 마케팅 캠페인 및 사내 행사 가이드라인 문서를 검색합니다.

GCS RAG 실습 프롬프트
넥스트 테크놀로지스의 사내 브랜드 앰버서더 참여 요건과 전용 VIP 혜택이 무엇인지 요약해줘
💡 추가 프롬프트: 넥스트월드 토크콘서트 개최 일정, 시간, 대강당 위치, 그리고 초청 강사를 정확히 가이드해줘
GCS 실시간 검색 답변
참조 출처 및 원본 문서 링크
3.3 RAG OPTIMIZATION & GOVERNANCE

검색 정확도를 극대화하는 문서 작성 & 청킹 3대 수칙

AI가 사내 문서를 가장 정확하게 이해하고 인용할 수 있도록 지식 베이스를 관리합니다.

1
명확한 헤딩(H1/H2/H3) 구조화
단락 구분이 명확할수록 시맨틱 청킹(Semantic Chunking) 스코어가 높아져 질문과 정확히 일치하는 단락이 검색됩니다.
2
시각 자료(표/차트) 텍스트 병기
이미지만 있는 차트나 다이어그램 하단에 표(Table)나 핵심 요약 수치를 텍스트로 함께 기재하여 검색 누락을 방지합니다.
3
구버전 문서 아카이빙
이전 연도 상충 규정 문서는 별도 아카이브 폴더로 격리하여 항상 최신 유효 규정만 답변에 인용되도록 수명주기를 관리합니다.
