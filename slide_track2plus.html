Part A. Connector 실습 전 확인 사항

Drive 커넥터를 사용하려면 Gemini Enterprise 어드민이 조직 단위로 커넥터를 미리 활성화해야 합니다.
커넥터 목록이 보이지 않거나 Enable actions 버튼이 없으면 강사에게 먼저 문의합니다.

🔐 Drive RAG 작동 방식

사용자가 권한 승인을 완료하면 Gemini가 본인의 Drive 파일을 직접 검색합니다. 권한이 없는 파일은 검색 대상에서 제외되므로 IAM 접근 제어가 철저히 유지됩니다.

⚠️ 시작 전 체크리스트

  • 어드민 콘솔에서 Drive 커넥터 활성화 완료 확인
  • 커넥터 목록에 Drive 항목 표시 확인
  • Enable actions 버튼 노출 확인
  • 버튼 미노출 시 강사에게 지원 요청

A.1 Google Drive 권한 승인 절차

연동 버튼을 클릭하고 계정을 선택하면 완료됩니다. 최초 1회만 진행합니다.

💡 계정 선택 팝업이 나타나지 않을 때: 브라우저 주소창 오른쪽의 팝업 차단 아이콘을 클릭해 '항상 허용'으로 바꾼 뒤 페이지를 새로고침합니다.

A.2 Drive RAG 실습

Drive에 업로드한 문서를 Gemini가 직접 검색합니다. 실습 전 Google Search를 끄고 진행합니다.

📥 실습 준비

  • 공통 내규 PDF를 로컬에 다운로드
  • 실습용 Google Drive에 업로드
  • Gemini 대화창에서 Google Search OFF
내 드라이브에 있는 "복리후생" 문서를 기반으로 자녀 학자금 지원 한도가 재직 기간에 따라 어떻게 다른지 알려줘

✅ 결과 확인 포인트

답변 하단의 인용 마커를 클릭하면 출처 문서로 바로 이동합니다. 마커가 보이면 Drive에서 직접 검색된 것입니다.

A.2 GCS RAG 실습

Google Cloud Storage 버킷에 저장된 데이터를 Gemini가 검색합니다. 어드민이 Vertex AI Search 데이터스토어를 사전에 구성한 경우 진행합니다.

⚠️ 어드민 사전 설정 필요

  • GCS 버킷 생성 및 샘플 파일 적재 완료
  • Vertex AI Search 데이터스토어 생성 및 버킷 연결
  • GCS 커넥터 어드민 콘솔 활성화 완료
  • 참가자 계정에 IAM 접근 권한 부여 완료

GCS 환경이 없으면 마케팅 내규 PDF를 Drive에 올리고 동일한 방식으로 테스트합니다.

📋 실습 프롬프트

넥스트 테크놀로지스의 사내 브랜드 앰버서더 참여 요건과 전용 VIP 혜택이 무엇인지 요약해줘
넥스트월드 토크콘서트 개최 일정, 시간, 대강당 위치, 그리고 초청 강사를 정확히 가이드해줘

RAG-Ready 문서 작성 3가지 수칙

RAG 검색 정확도는 원본 문서 구조에 직접 영향을 받습니다. 문서를 업로드하기 전에 아래 수칙을 적용하면 오답을 줄일 수 있습니다.

📊 이미지에 텍스트 병기

차트나 다이어그램 아래에 핵심 데이터를 표로 한 번 더 정리합니다. 구조화된 텍스트가 함께 있을 때 임베딩 검색 정확도가 대폭 향상됩니다.

📋 헤딩 계층 구조화

H1, H2, H3 스타일을 명확히 구분해 작성합니다. 단락 구분 없이 나열된 텍스트보다 계층 구조가 있는 문서가 청킹 시 관련성 점수를 더 높게 받습니다.

🗂️ 구버전 문서 정리

같은 내용의 구버전과 신버전이 함께 있으면 Gemini가 최신본을 판단하기 어렵습니다. 구버전은 주기적으로 아카이브 폴더로 이관합니다.

B.1 에이전트 코드 작성 & Cloud Run 배포

ADK로 Python 에이전트를 작성하고 to_a2a()로 A2A 서버로 변환한 뒤, 명령어 한 줄로 Cloud Run에 배포합니다.

① + ② Python 코드 예시

from google.adk.agents import Agent
from google.adk.a2a.utils import to_a2a

def my_tool(query: str) -> str:
    # 비즈니스 로직 구현
    return result

root_agent = Agent(
    model='gemini-2.5-flash',
    name='my_agent',
    description='업무 자동화 에이전트',
    tools=[my_tool],
)

# A2A 서버 변환 + Agent Card 자동 생성
app = to_a2a(root_agent)

③ Cloud Run 배포

adk deploy cloud_run \
  --service_name=my-agent \
  --project $PROJECT \
  --region $REGION \
  --a2a my_agent/

배포 완료 시 Agent Card가 <Cloud Run URL>/a2a/.well-known/agent-card.json 경로에 자동 게시됩니다.

B.1 Gemini Enterprise 어드민 등록

Cloud Run에 배포된 에이전트를 Gemini Enterprise 어드민 콘솔에 등록합니다. 등록이 완료되면 사용자 대화창에서 바로 호출할 수 있습니다.
