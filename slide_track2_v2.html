🎙️ 2인 대담 오디오 생성 절차

  • 생성하기(Generate) 버튼 클릭 (소요 시간: 약 2~4분)
  • 완료 후 실시간 스트리밍 청취 또는 MP3 파일 다운로드
  • Customize 옵션으로 대화의 집중 주제 지정 가능
⏱️ 소요 시간: 원클릭으로 5~8분 분량 자연스러운 대화형 오디오 완성

  • 출퇴근/이동 중 학습: 이어폰으로 사내 핵심 신기술 문서 청취

Deep Research: 다단계 자율 추론 & 웹 심층 탐색

단일 검색을 넘어 복합 질의를 하위 과제로 분해하고 수십 회 자율 탐색하여 종합합니다.

⚙️ Deep Research 4단계 작동 원리
  • 1. 질문 분해: 복합 문제를 5~10개의 세부 검색 키워드로 분할
  • 2. 다단계 탐색: 최대 160+ 웹페이지를 자율적으로 크롤링 및 수집
  • 3. 교차 검증: 상반된 통계와 주장을 비교하여 신뢰도 필터링
  • 4. 종합 보고서: 각주 인용이 완비된 다면 분석 보고서 작성
⏱️ 작동 시간: 3~7분간 백그라운드에서 자율 탐색 후 완전한 보고서 산출
🔍 일반 검색 vs Deep Research 비교
일반 검색 AI: 1~2개 쿼리로 검색된 상위 3개 문서 기반 단문 답변
Deep Research: 수십 개 쿼리 파생, 보고서 원문 PDF 심층 독해, 10페이지 분량 구조화 보고서
📊 컨설팅 펌 보고서 수준의 깊이 있는 산업 분석 완성
🔬 Deep Research 성능
수작업 2일 리서치 ➔ 5분 내 고품질 리포트 완성

실습 1. CRAFT 프롬프트 코치 에이전트 제작

사용자의 모호한 요청을 C.R.A.F.T 5요소로 분석하여 완성형 프롬프트로 변환하는 코치입니다.

⚙️ 에이전트 설정 스펙
  • Name: CRAFT Prompt Optimizer
  • Description: 모호한 지시어를 엔터프라이즈 CRAFT 프롬프트로 리팩토링
  • Instructions: 사용자가 질의를 입력하면 5단계 요소를 검토하고 누락된 맥락을 채워 최종 프롬프트 코드 블록을 제공할 것
🎯 목표: 전사 임직원의 프롬프트 작성 역량 상향 평준화
📋 시스템 지시어 (System Instructions)
Agent System Prompt
너는 엔터프라이즈 CRAFT 프롬프트 전문 코치야. 사용자가 거친 요청을 보내면: 1. 부족한 요소(Context, Role, Action, Format, Tone)를 진단하고 2. 즉시 복사하여 사용할 수 있는 완성된 [CRAFT 프롬프트]를 코드 블록으로 제시해. 3. 왜 그렇게 수정했는지 1줄 설명을 덧붙여.
✨ 에이전트 테스트 결과
"보고서 써줘" 입력 ➔ Context, Role, Action, Format, Tone이 명시된 완벽한 프롬프트 즉시 출력
