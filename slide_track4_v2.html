MODULE 4.1

BigQuery Data & SQL Analytics Agent

스키마 자동 파악 및 읽기 전용 표준 SQL 실행을 통한 경영진 브리핑 리포트 자율 생성

💬 시나리오 1 프롬프트
bigquery-public-data.thelook_ecommerce.orders 테이블의 스키마를 확인하고, 주문 상태(status)별 주문 건수 상위 5개를 집계해서 표와 3줄 핵심 인사이트로 브리핑해줘.
💬 시나리오 2 프롬프트
thelook_ecommerce 데이터셋에서 배송 완료(Complete)된 주문의 성별(gender) 분포와 평균 구매 품목 수를 분석해줘.
주문 상태 집계 결과 🔍 확대
성별 분포 분석 결과 🔍 확대
📊 2단계 자율 분석 체인
1단계: get_table_schema (컬럼 & 타입 탐색) 2단계: query_bigquery_table (SELECT/WITH 실행) 3단계: 3줄 핵심 인사이트 표 브리핑
