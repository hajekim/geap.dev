Act 1. 엔터프라이즈 인증 & 보안

커넥터 연동 전 환경 점검 & Zero Data Leak

Drive 커넥터를 사용하려면 어드민이 조직 단위로 커넥터를 활성화해야 합니다.

🔐 Zero Data Leak 핵심 메커니즘
1. User-Delegated Token
공용 계정이 아닌 로그인한 사용자 본인의 단기 OAuth 토큰으로 파일 검색 수행
2. Real-time ACL Inheritance
원본 드라이브 열람 권한이 없는 문서는 색인 단계에서 100% 필터링되어 노출 불가
3. VPC Service Controls
지정된 엔터프라이즈 보안 반경 외부로 비정형 원문 데이터 반출 원천 차단
⚠️ 시작 전 환경 점검 4대 체크포인트
⚙️ 1. 어드민 콘솔 활성화
조직 단위로 Google Drive 엔터프라이즈 커넥터 On 상태 확인
🔍 2. 대화창 커넥터 노출 확인
Gemini 대화창 우하단 @메뉴에서 Google Drive 아이콘 표시 확인
🔑 3. Enable actions 승인
사용자별 최초 1회 읽기 전용 OAuth 권한 승인 창에서 Allow 클릭
🌐 4. 브라우저 팝업 허용
주소창 우측 아이콘을 클릭하여 팝업 차단 해제 필수
🔑 커넥터 보안 표준
OAuth 2.0 User-Delegated Token
실시간 ACL 상속
VPC Service Controls 경계 내 실행

Act 3. Google ADK 2.0

Python ADK 코드 예시 & Cloud Run 배포

비즈니스 로직을 함수로 정의하고 to_a2a()로 변환하여 서버리스로 배포합니다.

💻 Python ADK 에이전트 소스코드
from google.adk.agents import Agent
from google.adk.a2a.utils import to_a2a

def check_inventory(sku: str) -> str:
    """ERP 재고 수량을 조회하는 커스텀 도구"""
    return f"SKU {sku}: 현재 재고 142개 (정상)"

root_agent = Agent(
    model='gemini-2.5-flash',
    name='inventory_bot',
    description='사내 재고 실시간 조회 에이전트',
    tools=[check_inventory],
)

app = to_a2a(root_agent) # A2A 표준 엔드포인트 자동 래핑
☁️ Cloud Run 원클릭 배포 명령어
Deploy CLI
adk deploy cloud_run \ --service_name=inventory-agent \ --project=$PROJECT_ID \ --region=asia-northeast3 \ --a2a inventory_agent/
📌 배포 완료 시 Agent Card URL 자동 생성:
https://<SERVICE_URL>/a2a/.well-known/agent-card.json
