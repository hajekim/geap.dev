3.1

Google Drive 및 Workspace 권한 승인

사내 드라이브 문서를 검색하고 요약하기 위해 최초 1회 OAuth 동의를 완료합니다.

1

대화창 오른쪽의 커넥터 아이콘을 클릭하고 Drive 항목의 Enable actions 버튼을 누릅니다.

2

구글 계정 선택 팝업이 뜨면 실습용 계정을 선택합니다.

3

권한 요청 화면에서 Allow를 클릭하여 승인합니다.

4

Drive 항목이 Disable actions 상태로 바뀌면 연동이 완료됩니다.

1단계: 커넥터 활성화 메뉴
2단계: 실습용 구글 계정 선택
3단계: OAuth 권한 승인 화면
4단계: Drive 연동 완료 (Disable actions)
💡 팝업 차단 트러블슈팅
계정 선택 창이 나타나지 않고 무한 로딩이 걸릴 때는 브라우저 주소창 우측의 팝업 차단 아이콘을 눌러 항상 허용으로 변경한 뒤 새로고침합니다.
3.2

사내 정보 검색 및 클라우드 지식 RAG 탐색

구글 드라이브 및 사설 클라우드 저장소에 보관된 사내 규정 문서를 RAG 검색합니다.

1) Google Drive 사내 복리후생 내규 RAG 질의

대화창 왼쪽 아래 커넥터에서 Google Search는 끄고 Drive만 활성화한 상태에서 실행합니다.

Drive RAG 사내 복리후생 내규 질문
내 드라이브에 있는 "복리후생" 문서를 기반으로 자녀 학자금 지원 한도가 재직 기간에 따라 어떻게 다른지 알려줘
Drive 커넥터 활성화 후 질문 입력
커넥터 최초 승인 넛지
커넥터 계정 승인 선택
문서 기반 정확한 답변 도출
클릭 시 원본 문서 위치 하이라이트

2) GCS 사설 저장소 RAG 검색 (마케팅 캠페인)

GCS RAG 사내 브랜드 앰버서더 요건 및 VIP 혜택 질의
넥스트 테크놀로지스의 사내 브랜드 앰버서더 참여 요건과 전용 VIP 혜택이 무엇인지 요약해줘
앰버서더 가이드라인 질의 결과
답변 출처 목록 확인
GCS RAG 토크콘서트 일정 및 초청 강사 질의
넥스트월드 토크콘서트 개최 일정, 시간, 대강당 위치, 그리고 초청 강사를 정확히 가이드해줘
행사 일정 질의응답 결과 화면
💡 RAG 검색 정확도를 높이는 문서 작성 3대 수칙
  • 시각 자료 텍스트 병기: 차트나 다이어그램 이미지 아래에 표나 텍스트 요약을 함께 적어둡니다.
  • 명확한 헤딩(H1, H2, H3) 구조화: 단락 구분이 잘 된 문서일수록 청킹(Chunking) 검색 스코어가 높아집니다.
  • 구버전 문서 아카이브: 상충되는 이전 버전 문서는 별도 아카이브 폴더로 이동하여 혼선을 방지합니다.

from google.adk.agents import Agent from google.adk.a2a.utils import to_a2a def my_custom_tool(query: str) -> str: # 사내 비즈니스 로직 및 외부 API 연동 return f"결과: {query}" root_agent = Agent( model='gemini-2.5-flash', name='custom_business_agent', description='사내 업무 자동화 전담 에이전트', tools=[my_custom_tool], ) # A2A 프로토콜 변환 및 Agent Card 자동 생성 app = to_a2a(root_agent)
