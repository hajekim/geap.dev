Step 2.1.1 인포그래픽 제작

🎨 3종 스타일 인포그래픽 (기본 · 스케치 · 신문)

Google AI 서비스 텍스트 3종을 소스로 업로드하고 개요 · 스케치노트 · 신문 1면 스타일의 인포그래픽을 생성합니다.

📥 실습 절차

  • Google AI 서비스 텍스트 3종을 노트북 소스로 추가
  • 우측 Studio → Infographic (⋮) → Customize
  • Workspace 소스 → 기본 스타일 생성
  • Gemini 소스 → 스케치노트 스타일 생성
  • Cloud 소스 → 신문 1면 스타일 생성

📋 스타일별 프롬프트

Google Workspace 주요 앱과 Gemini AI 연동 기능을 한눈에 정리한 인포그래픽을 만들어줘
Google Gemini Enterprise 핵심 기능과 실무 활용 시나리오를 스케치노트 스타일로 그려줘
Google Cloud Vertex AI와 BigQuery 기반 기업 AI 혁신을 신문 1면 기사 스타일로 만들어줘
Step 2.1.2 오디오 팟캐스트

🎙️ Audio Overview (AI 2인 대담 요약)

소스 문서 전체를 AI 진행자 2인의 팟캐스트 대담 형식으로 자동 요약합니다. 5~8분 분량의 오디오가 자동 완성됩니다.

⚙️ 생성 방법

  • 노트북 우측 오디오 개요 패널 열기
  • 생성하기 버튼 클릭 (소요 시간: 약 2~4분)
  • 생성 완료 후 실시간 스트리밍 재생 또는 MP3 다운로드

💡 실무 활용 가치

  • 이동 중 이어폰으로 핵심 기술 문서 학습
  • 신규 입사자 및 부서 온보딩 오디오 브리핑 자료 배포
  • 사내 메신저 및 메일로 간편한 지식 공유
Step 2.1.3 시네마틱 슬라이드

📊 Slide Deck (시네마틱 비주얼 슬라이드)

제품 이미지만으로 Gemini Notebook이 영화 예고편 스타일의 슬라이드를 자동 완성합니다. 라이프스타일 브랜드 '홈스타일' 시나리오로 실습합니다.

📥 실습 절차

  • homestyle.zip 다운로드 후 이미지 4장 소스 업로드
  • 브랜드 스토리 텍스트를 story 소스로 추가
  • 슬라이드 자료 → Customize 옵션 선택 후 프롬프트 입력

📋 Customize 프롬프트

스토리에 맞는 시네마틱 슬라이드를 만들어줘, 타이틀, 텍스트, 자막, 설명 등은 포함하지 마

💡 텍스트 없이 이미지만으로 구성된 세련된 비주얼 슬라이드 완성

Step 2.1.4 리포트 자동 생성

📖 Reports (Study guide · FAQ · Briefing doc)

소스를 기반으로 Study guide · FAQ · Briefing doc 3종 문서를 클릭만으로 자동 생성합니다.

📚 Study guide

소스 전체를 핵심 개념 → 세부 내용 순서로 자동 정리하여 신규 기술을 빠르게 학습합니다.

❓ FAQ

문서에서 자주 묻는 질문과 답변을 자동 추출하여 고객 응대 및 팀 Q&A 자료로 즉시 활용합니다.

📋 Briefing doc

핵심 내용을 경영진 보고용 1페이지로 압축 요약하여 의사결정 브리핑 시간을 단축합니다.

Step 2.1.5 튜토리얼 비디오

🎬 Video Overview (Canvas 튜토리얼 비디오)

canvas.pdf와 이미지를 소스로 업로드하고 Customize 프롬프트로 단계별 튜토리얼 영상을 생성합니다.

📥 실습 절차

  • canvas.pdf + canvas.zip 다운로드 후 소스 업로드
  • 우측 Video Overview 패널 → Customize 선택
  • 프롬프트 입력 후 생성 — 완료 시 MP4 비디오 다운로드

📋 Customize 프롬프트

Gemini Enterprise에서 Canvas를 사용하는 방법을 초보자도 따라가기 쉽게 차근차근 설명하는 동영상을 만들어줘

Step 2.2 Deep Research

심층 다단계 리서치 보고서 구조화

단편적인 검색 요약을 넘어, 신뢰할 수 있는 학술/산업 분석 문서와 동일한 수준의 체계적 결과물을 산출합니다.

📑 보고서 핵심 구성 요소

  • Executive Summary: 의사결정권자를 위한 핵심 요약 (3줄)
  • Market Dynamics: 시장 성장 동인 및 위협 요인 상세 분석
  • Competitive Matrix: 주요 경쟁사별 기술 및 가격 비교표
  • Verified Citations: 인용된 모든 출처 웹 링크 투명 공개

🎙️ 1~2분 오디오 요약 브리핑

보고서 생성과 동시에 핵심 요점을 1~2분 분량의 음성 브리핑 오디오로 변환하여 경영진에게 메일이나 메신저로 즉시 전달할 수 있습니다.

에이전트 아키텍처

차세대 업무 에이전트 5대 실무 아키타입

비즈니스 목적 및 데이터 유형에 따라 분류되는 엔터프라이즈 에이전트의 주요 구성 방식입니다.

1️⃣ 지식 검색 (RAG)

주요 기능: 사규집 및 매뉴얼 데이터 검색
적용 예시: 사내 복리후생 Q&A, 규정 대조 봇

2️⃣ 데이터 분석 (Data)

주요 기능: 정형 DB 질의 및 차트 시각화
적용 예시: KPI 집계, 매출 실시간 분석

3️⃣ 콘텐츠 생성 (Content)

주요 기능: 다국어 번역 및 서식 변환
적용 예시: 대외 PR 초안, 소셜 미디어 게시물

Step 2.3 Agent Designer

Agent Designer 노코드 에이전트 빌더 개요

개발 코딩 없이 자연어로 에이전트를 만들고 조직에 배포하는 노코드/로우코드 에이전트 스튜디오입니다.

📋 에이전트 유형

  • Custom agent: 자연어 지시어 하나로 즉시 생성하는 단일 목적 에이전트
  • Workflow agent: Flow Builder로 서브에이전트를 단계별 조율하는 멀티 에이전트

⚙️ 핵심 제작 도구

  • Chat Pane: 자연어로 에이전트를 조립 및 수정하는 대화창
  • Flow Builder: 노드와 소스를 시각적으로 연결하는 캔버스
  • Preview: 배포 전 실시간 인터랙티브 동작 검증
Step 2.3.1 에이전트 실습 1

🤖 CRAFT 프롬프트 코치 에이전트 제작

CRAFT 프레임워크를 내장한 프롬프트 최적화 코칭 에이전트를 Agent Designer로 직접 제작합니다.

📥 실습 절차

  • Agents 메뉴 → New Agent 클릭
  • Chat Pane에 CRAFT 설계 요구 명세 입력
  • Flow Builder에서 세부 설정 검토
  • Preview로 에이전트 동작 테스트 후 Create 배포

📋 에이전트 생성 프롬프트

사용자가 러프하게 작성한 프롬프트를 Gemini에 사용하기 좋도록 아래 CRAFT 프레임워크 기반으로 프롬프트를 재작성합니다. 작성하기 위해 너(Gemini)에게 어떤 정보가 필요한지 나에게 질문하여 얻습니다.
Step 2.3.2 에이전트 실습 2

📱 소셜 미디어 게시물 자동 생성 에이전트

원문 기사나 보도자료를 입력받아 LinkedIn, X(Twitter), 사내 블로그용 게시물로 멀티 채널 변환하는 에이전트입니다.

🎯 다채널 맞춤 변환 규칙

  • LinkedIn: 비즈니스 인사이트 및 전문적인 톤, 해시태그 3개 포함
  • X (Twitter): 280자 이내 강렬한 훅(Hook)과 이모지 활용
  • 블로그: 서론-본론-결론 구조의 정돈된 본문 초안

💡 실무 기대 효과

마케팅 및 홍보 부서에서 1개의 원본 보도자료로 3대 채널의 홍보 콘텐츠를 10초 만에 동시 발행할 수 있습니다.

Step 2.4 Workflow Agent

⚙️ Workflow Agent (다단계 오케스트레이션)

복잡한 업무를 순차적 단계(Step)로 분해하고, 각 단계를 전담 서브에이전트가 실행하는 멀티 에이전트 방식입니다.

🔄 순차 실행 파이프라인

각 노드가 독립적인 Instruction·Knowledge·Tools·Model 설정을 가지며 순서대로 실행됩니다.

⏰ 스케줄러 자동 트리거

정해진 시간이나 웹훅 이벤트에 Workflow Agent를 자동 실행하여 주기적 업무를 무인 자동화합니다.

👤 Human-in-the-loop

중간 단계에 사람의 검토·승인·입력을 삽입하여 중요한 비즈니스 결정을 안전하게 통제합니다.

Step 2.4 Workflow Agent 실습

시장 조사·경쟁 분석 4단계 워크플로우

Web Grounding으로 최신 동향을 수집하고, 단계별 분석을 거쳐 경영진 보고서를 자동 작성하는 Workflow Agent를 구축합니다.

📥 실습 절차

  • Agents → New Agent > Workflow Agent 클릭
  • Chat Pane에 시장 분석 에이전트 프롬프트 입력
  • 생성된 노드 구조 확인 후 Preview → Start manually 실행
  • Human-in-the-loop 단계에서 분석 대상 키워드 입력

🔄 4단계 분석 파이프라인

  • Step 1 (수집): Web Grounding 실시간 시장 뉴스 수집
  • Step 2 (분석): SWOT 및 경쟁사 전략 매트릭스 도출
  • Step 3 (작성): Executive Summary & 액션 플랜 작성
  • Step 4 (제안): 후속 실행을 위한 추천 질문 3개 도출
Step 2.4 Workflow Agent 실습

시장 분석 실행 결과 및 경영진 보고서 검증

Workflow Agent가 각 노드를 거치며 최종적으로 완성한 정형화된 경영진 브리핑 문서를 검토합니다.

Track 2 요약 및 핵심 성과 점검

Gemini Notebook과 Agent Designer를 통해 노코드 환경에서 달성할 수 있는 비즈니스 가치입니다.

✨ 달성된 핵심 역량

  • 사내 문서 소스 기반 5종 멀티미디어 콘텐츠 즉시 생성
  • Deep Research를 통한 160회 자율 심층 리서치 수행
  • 자연어로 업무 특화 에이전트 즉시 조립 및 배포

📈 비즈니스 생산성 변화

시장 조사 보고서 작성 시간 5일 → 30분 단축, 팀 온보딩 자료 제작 1주일 → 10분 완성으로 기획 생산성이 획기적으로 향상됩니다.
